## 目标

点击首页基金列表项 → 打开基金详情页，展示：
1. **十大持仓股当日涨跌**：持仓列表（名称/代码/占比/市值），每只股票带当日实时涨跌幅 + 涨跌标签徽标（涨=焦墨实心、跌=淡墨空心，与首页风格统一）。
2. **区间涨跌曲线**：可筛选「当日 / 近一周 / 近一月 / 近一年」四个周期的净值走势折线图。

## 调研结论（已与用户确认的决策）

- **页面形态**：新建独立 `FundDetailActivity`（与现有 SearchActivity/SettingsActivity 风格一致，Toolbar 返回）。
- **当日曲线**：退化为「今日净值 vs 昨日」的涨跌对比（不画分时曲线）；主推近一周/近一月/近一年区间曲线。
- **持仓展示**：列表 + 涨跌幅 + 标签徽标。

## 现有可复用资产（避免重复造轮子）

| 能力 | 现状 | 复用方式 |
|------|------|----------|
| 持仓解析 | `EastMoneyApi.fetchHoldings()` 已解析 `ccmx` 表 → `HoldingsResult` | 直接复用 |
| 股票批量行情 | `TencentQuoteApi.fetchBatchChangePercent()` 已实现 | 直接复用 |
| 区间净值曲线 | 无，需新增 | 新增解析 `pingzhongdata/{code}.js`（已验证含全量净值 `Data_netWorthTrend` + `equityReturn` 日涨跌，及近一月/近一年收益率字段） |
| 曲线图 | MPAndroidChart（`libs.mpandroidchart` 已在依赖） | 直接复用，墨水屏灰阶配色 |
| 涨跌徽标样式 | `bg_badge_up/down/flat.xml` + `price_up/price_down` 色 | 直接复用 |
| 数据模型 | `HoldingsResult`、`NavResult`（date/nav/growth 已齐全）、`ChartPoint` | 直接复用 |

## 实现步骤

### 1. 数据层

**1a. 新增 `EastMoneyApi.fetchPingzhongData(String fundCode)`**
- 请求 `https://fund.eastmoney.com/pingzhongdata/{code}.js`（UTF-8，`Referer: https://fund.eastmoney.com/`）。
- 用正则/字符串解析 JS 变量：`Data_netWorthTrend`（含 `x` 毫秒时间戳、`y` 净值、`equityReturn` 日涨跌）、`fS_name`（名称）。
- 返回结构：全量净值点列表 `List<NavResult>`（date/nav/growth），一次性拿全量再在 UI 层按区间裁剪（近一周/一月/一年按 `Constants.CHART_DAYS_*` 常量）。

**1b. `FundRepository` 新增两个方法**
- `fetchHoldingsWithQuotes(String fundCode)` → `Observable<HoldingsResult>`（已有，但当前只拿持仓，需在详情页组合行情）。
- `fetchNavHistory(String fundCode)` → `Observable<List<NavResult>>`（调 1a）。
- 新增 `fetchHoldingsWithStockQuotes(String fundCode)`：`fetchHoldings` 后用 `fetchBatchChangePercent` 批量补股票当日涨跌幅，产出「持仓 + 涨跌幅」的组合模型（新建 `HoldingStockWithQuote` 或在 `HoldingsResult.HoldingStock` 上加 `changePercent` 字段）。

**1c. 股票代码 → 市场前缀映射**（腾讯行情 `sz`/`sh`）
- 6 开头 → `sh`，0/3 开头 → `sz`（常量 `SZ_PREFIX`/`SH_PREFIX` 已有）。

### 2. 详情页 UI（新建 `FundDetailActivity` + `activity_fund_detail.xml`）

**顶部信息区**：基金名称（衬线标题）、代码、当日净值（`dwjz`）+ 日涨跌幅（复用 `FundViewHolder` 的涨跌徽标逻辑，从 `FundEntity` 传入）。

**区间曲线区**：
- 顶部四个筛选 Chip（当日 / 近一周 / 近一月 / 近一年），`TextView.setSelected` 样式复用首页排序 Chip 的选中态。
- 下方一个 `MPAndroidChart LineChart`：
  - **近一周/近一月/近一年**：从 `pingzhongdata` 全量数据裁剪对应天数（1 周=7、1 月=30、1 年=365，复用 `Constants.CHART_DAYS_*`）。
  - **当日**：显示「今日净值 vs 昨日净值」的涨跌幅文本对比（不画曲线，因为已确认无稳定分时数据源；若只有单点则展示当日涨跌幅大字）。
  - 灰阶配色（`price_up`/`price_down`/`ink_mid`），关闭网格/图例/缩放，保留日期 x 轴标记。

**十大持仓区**：
- `RecyclerView` + 新建 `HoldingStockAdapter`，每行：名称、代码、持仓占比、市值 + 右侧当日涨跌幅 + 涨跌徽标（复用 `bg_badge_*`）。
- 加载中 / 加载失败（提示重试）状态。

**加载交互**：进入页面加载（ProgressBar / 骨架），持仓与曲线并行请求；失败可点击重试。

### 3. 导航接线

- `Home.java` 里 `FundListAdapter` 的点击回调当前是空实现（`// 一期无详情页`），改为 `startActivity(new Intent(...FundDetailActivity.class).putExtra("fundCode", fund.getCode()))`。
- `AndroidManifest.xml` 注册 `FundDetailActivity`（`exported="false"`）。

### 4. 复用仓库层的组合查询

在详情页 ViewModel（新建 `FundDetailViewModel` 或直接复用 `FundRepository` + CompositeDisposable，参照 `SearchActivity` 的写法）中组合两个请求（曲线 + 持仓），`CompositeDisposable` 管理生命周期。

## 验收点

- 点击首页任意基金卡片 → 打开详情页，显示基金名/代码/当日净值涨跌。
- 十大持仓列表每行显示：名称、代码、占比、市值、当日涨跌幅、涨跌徽标；数据来自腾讯批量行情。
- 四个区间 Chip 切换 → 折线图对应更新（近一周/近一月/近一年有真实曲线，当日显示净值对比）。
- 无持仓数据 / 网络失败时给出空态与重试。
- 整体配色与墨水屏风格一致（灰阶、衬线标题、墨色浓淡代替红绿）。
