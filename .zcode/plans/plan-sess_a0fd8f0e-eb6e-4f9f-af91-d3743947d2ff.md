# 水墨丹青 UI 效果图(HTML)

## 产出
新建 `design/home_ink.html`(保留旧稿不覆盖),单文件、Tailwind CDN + Google Fonts(与现有 design/*.html 惯例一致),用浏览器直接打开即可预览「自选」Tab 效果。

## 设计内容(水墨丹青方向 A + 完整中国风处理)

**色彩(已定稿色板)**
- 宣纸底 `#F5F1E8` + CSS 噪点渐变模拟纸张质感
- 纸白卡片 `#FFFFFF`、墨黑文字 `#1F1F1F`、辅助灰 `#9A9488`
- 黛青主色 `#3A4A5A`(选中态/按钮)、朱砂点睛 `#C0392B`(仅印章)
- 涨 `#E53935` / 跌 `#2E7D32`(红涨绿跌)

**中国风三要素**
1. 印章 Logo:顶部栏左侧,朱砂红方印 CSS 绘制,白字「咕咕鸡印」2×2 篆排
2. 衬线标题:Noto Serif SC(思源宋体),App 名与卡片基金名用衬线;数字用无衬线等宽保持清晰
3. 宣纸质感:页面底色米白 + 细噪点纹理,卡片细墨色描边(`#E0D9CC`),列表间水墨细线

**页面结构(对应一期产品:无持仓/盈亏)**
- 顶部栏:印章 + 衬线「咕咕鸡」+ 搜索/刷新图标
- 汇总条:纯估值展示(估值时间 + 市场状态),替代旧版盈亏卡片
- 基金列表 3–4 条示例:基金名(衬线)+ 代码 | 估算净值(大号等宽数字)+ 涨跌幅徽标(红/绿,同色 10% 浅底圆角块),含一条平盘/停牌态
- 空态/细节:留白充分、水墨分隔线
- 底部 3 Tab:自选(选中·黛青)/ 圈子 / 我的
