# 咕咕鸡 · 墨水屏(Kindle)设计规范

> 配套效果图:`design/home_eink.html`(浏览器直接打开可预览)
> 本规范是 App UI 的权威风格文档,Android 资源(colors/themes/drawable/字体)以此为准落地。

---

## 一、设计理念

**"墨水屏上的自选基金"**--整个 App 模拟 Kindle 电子墨水屏的观感:

- **无彩色**:界面完全灰阶,像 e-ink 屏一样只有"墨"与"纸"
- **墨分五色**:涨跌不用红绿,改用墨的浓淡区分层级(涨=浓墨,跌=淡墨)
- **屏幕即最白处**:e-ink 没有纯白,屏幕底色就是最亮的地方,卡片只能比底色亮一档,靠墨线勾边分区
- **像素硬朗**:边框锐利(致敬 e-ink 无抗锯齿的渲染),不用柔和阴影
- **纸书气质**:标题用衬线宋体,内容像一页排好版的电子书
- **克制动效**:唯一保留的动效是"刷新闪烁"(模拟 e-ink 全刷)

## 二、色板(墨分五色 · 中性灰)

| 语义 | 色值 | 用途 |
|------|------|------|
| 纸底 `paper` | `#E4E4E4` | 页面背景,全屏最亮处 |
| 卡片 `card` | `#EBEBEB` | 列表卡片/底部栏,仅比纸底亮一档 |
| 焦墨 `ink` | `#171717` | 最强对比:选中态、涨徽标、FAB、印章底 |
| 重墨 `ink-heavy` | `#2E2E2E` | 标题、净值数字正文 |
| 淡墨 `ink-mid` | `#696969` | 二级文字(昨日净值数值) |
| 清墨 `ink-faint` | `#9A9A9A` | 辅助文字(代码、时间、脚注) |
| 主边框 `line-strong` | `#2A2A2A` | 卡片描边、顶/底栏分割线(1.5px) |
| 浅分隔 `line-soft` | `#C8C8C8` | 卡片内部分隔线、次级描边(1px) |

**原则**:全部为中性灰(RGB 三通道相等或近似),禁止暖色/冷色偏色;层级只靠灰阶差,最大亮度差控制在纸底与焦墨之间。

## 三、涨跌语义(墨的浓淡,替代红涨绿跌)

| 状态 | 样式 | 示例 |
|------|------|------|
| **涨** | 浓墨实心徽标:焦墨底 + 纸色字,带 `↑` 箭头 | `↑ +1.23%` |
| **跌** | 淡墨空心徽标:卡片底 + 焦墨字 + 1.5px 焦墨描边,带 `↓` 箭头 | `↓ -0.86%` |
| **平盘/停牌** | 虚线灰:卡片底 + 清墨字 + 虚线描边,卡片边框同步变虚线 | `--` / `0.00%` |

涨跌一律带 `+`/`-` 号与箭头,弥补无彩色后的辨识度。

## 四、字体

| 场景 | 字体 | 说明 |
|------|------|------|
| 品牌名/基金名(标题) | Noto Serif SC(思源宋体),600/700 | 纸书气质,衬线是本风格的识别符 |
| 正文/辅助文字 | Noto Sans SC,400/500 | 保证小字号可读性 |
| 所有数字 | Roboto Flex / 系统等宽,`tabular-nums` | 净值/涨跌幅跳动时宽度不抖动 |

数字字号阶梯:净值 **20px** 加粗;涨跌徽标 **12px** 加粗;辅助信息 **11–12px**。

## 五、组件规范

### 5.1 卡片(基金条目)

- 底色 `#EBEBEB`,**1.5px 焦墨实线描边**,圆角 4–6px(小圆角,保持硬朗)
- 无阴影、无渐变
- 结构:左上=基金名(衬线)+类型标签(细描边小标签)+代码/估值时间;右上=净值(20px 等宽)+涨跌徽标
- 卡片底部:1px 浅分隔线上方留 8px,横排"昨日净值 / 净值日期"
- 停牌卡片:边框整体改虚线,文字降级为淡墨

### 5.2 白文印(品牌 Logo)

- 42×42px,焦墨底 `#171717` + 纸色字 `#EBEBEB`,2px 纸色内框 + 4px 焦墨再框(阴刻双线)
- 内容「咕咕鸡印」2×2 篆排,衬线加粗 13px
- 圆角 6/4/5/4px(手工印章的不对称感)

### 5.3 徽标(涨跌幅)

- 圆角 4px,padding 2px 8px,字号 12px 加粗
- 涨:焦墨实心;跌:空心描边;停牌:虚线(见第三节)

### 5.4 按钮/筛选

- 选中:焦墨底 + 纸色字 + 1.5px 焦墨边
- 未选中:透明底 + 1.5px 浅边 + 清墨字,hover 时边框升为淡墨

### 5.5 底部导航(3 Tab:自选/圈子/我的)

- 卡片色底 + 顶端 1.5px 焦墨分割线
- 选中:焦墨实心圆角块(图标+文字反白),图标 FILL 填充
- 未选中:清墨,描边图标

### 5.6 FAB(添加基金)

- 48×48,焦墨底 + 纸色 + 号,圆角 8px(方形 FAB,不用圆形),无阴影

## 六、屏幕质感特效

| 特效 | 实现 | 说明 |
|------|------|------|
| **墨水颗粒** | SVG feTurbulence 噪点,中性灰,opacity ≈ 0.09,multiply 混合 | 模拟 e-ink 玻璃层颗粒 |
| **前光暗角** | 径向渐变:中心 58% 透明 -> 四角 `rgba(38,38,38,0.10)` | 模拟 Kindle 前光导光不均,四角微暗 |
| **刷新闪烁** | 点击刷新时 0.7s `steps(1,end)` 关键帧:反相 -> 全黑 -> 反相 -> 过曝 -> 复原 | 致敬 e-ink 全刷,唯一保留的动效 |

**注意**:不使用任何平滑过渡动画(e-ink 无过渡)、不使用阴影和渐变按钮;闪烁动效在真 e-ink 设备上应关闭(通过 `prefers-reduced-motion` 或设备判断)。

## 八、Android 落地映射

| Android 资源 | 内容 |
|--------------|------|
| `res/values/colors.xml` | 按第二节色板定义 `paper/card/ink/ink_heavy/ink_mid/ink_faint/line_strong/line_soft`,以及 `price_up`→焦墨、`price_down`→淡墨(语义改名) |
| `res/values/themes.xml` | Material3 主题:`colorPrimary` = 焦墨,背景 = paper,状态栏 = paper(与屏幕同色,无边框感) |
| `res/drawable/` | `bg_card.xml`(1.5dp 焦墨描边+小圆角)、`bg_card_dashed.xml`(停牌虚线版)、`bg_badge_up.xml`(实心)、`bg_badge_down.xml`(描边空心)、`bg_tab_selected.xml`(焦墨实心块) |
| `res/font/` | `noto_serif_sc.xml` 字体族(标题用衬线) |
| 深色模式 | e-ink 风格**不需要传统深色模式**;`values-night` 可保持同一套色板(墨水屏开背光时颜色不变),或仅整体压暗一档模拟关前光 |
| 动效 | 列表刷新不做平滑动画,直接整体替换;可选用 500ms 黑白反相 Transition 致敬全刷 |
